# Проект виджета банковских операций клиента.
## Цель проекта - Это виджет, который показывает несколько последних успешных банковских операций клиента. Данный проект на бэкенде будет готовить данные для отображения в новом виджете.
## В этом задании предстоит использовать Git для сохранения истории развития проекта. Реализуем новый функционал, делая небольшие коммиты.
## Задачи
### 1. Инициализировать новый локальный Git-репозиторий в папке проекта, используя команду git init
### 2. Создать файл .gitignore в корне проекта и добавить в него стандартный шаблон для Python, чтобы исключить системные и временные файлы, такие как pycache, .idea и другие. Для заполнения файла можно воспользоваться шаблоном.
### 3. Сделать минимум три коммита в процессе разработки кода, фиксируя основные этапы создания проекта. Например, первый коммит может быть фиксацией прогресса по прошлой домашке, второй — добавлением новых функций, третий — финальными изменениями и доработками.
### 4. В пакете src создать новый модуль с именем widget. Этот модуль будет содержать функции для работы с новыми возможностями приложения.
### 5. В модуле widget создать функцию mask_account_card, которая умеет обрабатывать информацию как о картах, так и о счетах.
